# Marketing — CSO → CMO → sub-skills

Two routing layers for the marketing function. Neither layer does the work; they classify and delegate.

```
orchestrator
  └── cso            (Chief Strategy Officer, top parent)     marketing/cso.md
        └── cmo      (Chief Marketing Officer, marketing parent) marketing/cmo.md
              ├── content_strategist                               marketing/content_strategist.md
              ├── copywriter                                       marketing/copywriter.md
              ├── campaign_tracker                                 marketing/campaign_tracker.md
              └── content_research                                 marketing/content_research.md
```

- **`cso.md`** — top parent. The orchestrator hands it a brief; it classifies the request by function and routes it to the right department head. Its only sub-agent today is the CMO.
- **`cmo.md`** — marketing parent. It classifies a marketing brief, attaches an audience tag, and routes each step to the correct marketing sub-skill.
- **sub-skills** — `role: subagent`, `parent: cmo`. They produce the work.

## Adding a marketing skill

Any `.md` file dropped into this folder with frontmatter `role: subagent` automatically becomes a CMO sub-skill.

1. Write the skill file here with `name`, `title`, `role: subagent`, and `parent: cmo`.
2. Rebuild the CMO's route list:

   ```powershell
   .\scripts\index-marketing-subagents.ps1
   ```

The script finds the marketing parent (the file with `role: parent` **and** a `parent:`), collects every `role: subagent` name in this folder, and rewrites the parent's `sub_agents:` block. New skills are appended automatically — the registry is generated, not hand-edited.

## Frontmatter contract

| Field | Used by | Meaning |
|---|---|---|
| `name` | all | Stable id the parent routes by. |
| `title` | all | Human-readable name. |
| `role` | all | `parent` or `subagent`. |
| `parent` | nested parents and sub-skills | Id of the layer above. Absent on the top parent. |
| `sub_agents` | parents | Ordered list of children. Generated by the script for the CMO. |
